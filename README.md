# DESOC Official Website

This repository contains the official DESOC website and the Genesis registration system.

DESOC pages include:
- Home and society highlights
- Event and past event sections
- Committee and alumni information
- Contact and gallery pages

Genesis registration includes:
- Team-based registration flow
- Team leader details
- Separate college and department details
- Additional member name and contact capture
- Payment screenshot upload and transaction tracking
- Backend save to MongoDB and Google Sheets

## Tech Stack

- Frontend: React, Vite, Tailwind CSS
- Backend: Node.js, Express, MongoDB
- Integrations: Cloudinary, Google Sheets API

## Run (Quick)

From project root:

1. Install frontend dependencies
	npm install
2. Start frontend
	npm run dev

From server folder:

1. Install backend dependencies
	npm install
2. Start backend
	npm run dev
